# Contributing to Awesome Private Equity

Thank you for your interest in contributing!

## Guidelines

- Ensure the resource is high-quality and genuinely useful to PE professionals.
- Prefer established, widely-used resources over newly launched products.
- Include a brief, objective description — not marketing copy.
- Free resources are preferred, but premium tools widely used in the industry are welcome.
- Maintain alphabetical order within categories where practical.

## How to Contribute

1. Fork this repository
2. Create a new branch (`git checkout -b add-new-resource`)
3. Add your resource in the appropriate section
4. Commit your changes (`git commit -m 'Add [Resource Name]'`)
5. Push to your branch (`git push origin add-new-resource`)
6. Open a Pull Request with a brief explanation

## What Not to Submit

- Self-promotional content without genuine industry adoption
- Paywalled content without indicating the cost
- Duplicate resources already listed
- Resources that are no longer maintained
